# Organization recommendations

This is planned work, not current behavior.

Recommendations must be evidence-based and optional, never generic text at the
end of every answer. A future review service should return at most one
high-confidence suggestion with a reason and proposed action. It must never
apply a change without a new user request.

The first concrete organization rules still need user-defined conventions; a
folder being “wrong” cannot be inferred reliably from a title alone.
